# ✨ Jewelry Shop

یک وب‌سایت مدرن و ریسپانسیو برای فروش زیورآلات که با **Vue.js 3** و **Vite** توسعه داده شده است.

این پروژه با تمرکز بر طراحی مدرن، تجربه کاربری روان و پیاده‌سازی قابلیت‌های اصلی یک فروشگاه آنلاین ساخته شده است.

## 🛠️ Technologies

* Vue.js 3
* Vite
* JavaScript
* Tailwind CSS
* Vue Router
* Lucide Icons
* LocalStorage

Vue 3 از معماری Component-Based و Single File Components استفاده می‌کند و این پروژه نیز بر همین اساس توسعه داده شده است.

## ✨ Features

### 🛍️ Products Page

صفحه محصولات شامل:

* نمایش محصولات زیورآلات
* کارت اختصاصی برای هر محصول
* نمایش تصویر، نام، قیمت و موجودی
* امکان اضافه کردن محصول به سبد خرید
* نمایش وضعیت موجودی محصول

### 🔎 Search

امکان جستجوی محصولات بر اساس نام محصول.

کاربر می‌تواند محصول موردنظر خود را به‌صورت سریع در میان محصولات پیدا کند.

### 🔽 Filter & Sort

امکان مرتب‌سازی محصولات بر اساس:

* ارزان‌ترین
* گران‌ترین
* حالت پیش‌فرض

### 📄 Pagination

محصولات در چند صفحه نمایش داده می‌شوند تا تعداد زیادی محصول بدون شلوغ شدن صفحه قابل مشاهده باشند.

### 🛒 Shopping Cart Sidebar

یک Sidebar برای مشاهده سریع سبد خرید در اختیار کاربر قرار گرفته است.

امکانات:

* مشاهده محصولات انتخاب‌شده
* افزایش تعداد محصول
* کاهش تعداد محصول
* حذف محصول
* نمایش تعداد محصولات
* نمایش قیمت هر محصول

### 🛒 Cart Page

صفحه اختصاصی سبد خرید شامل:

* لیست محصولات انتخاب‌شده
* تصویر محصول
* نام محصول
* قیمت
* تعداد
* افزایش و کاهش تعداد
* حذف محصول
* محاسبه مجموع قیمت

### 💾 LocalStorage

اطلاعات سبد خرید در `LocalStorage` ذخیره می‌شود تا با Refresh کردن صفحه، اطلاعات سبد خرید از بین نرود.

### 📱 Responsive Design

رابط کاربری برای اندازه‌های مختلف صفحه طراحی شده است:

* Desktop
* Tablet
* Mobile



## ⚙️ Installation

ابتدا پروژه را Clone کنید:

```bash
git clone YOUR_REPOSITORY_URL
```

وارد پوشه پروژه شوید:

```bash
cd jewelry-shop
```

سپس dependencies را نصب کنید:

```bash
npm install
```

برای اجرای پروژه در محیط توسعه:

```bash
npm run dev
```

برای ساخت نسخه Production:

```bash
npm run build
```

پروژه‌های جدید Vue معمولاً با `create-vue` و Vite ایجاد می‌شوند و اجرای توسعه نیز با `npm run dev` انجام می‌شود.

## 🧩 Cart Logic

منطق سبد خرید در یک composable به نام `useCart` مدیریت شده است.

برخی از قابلیت‌های اصلی:

```js
addToCart()
increase()
decrease()
totalPrice
```

برای محاسبه مجموع قیمت محصولات نیز از `computed` و `reduce` استفاده شده است.
